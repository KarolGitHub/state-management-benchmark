# Getting Started

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

Included apps:

- #1 (ReactJS - acts as the app shell plus is an aggregation with other remotes): [http://localhost:3000](http://localhost:3000)
- #2 (React Hooks - lets you use state and other React features without writing a class.): [http://localhost:3001](http://localhost:3001)
- #3 (Svelte - Compiler that generates minimal and highly optimized JavaScript code from our sources.): [http://localhost:3002](http://localhost:3002)
- #4 (Vue - Model–view–viewmodel front end JavaScript framework for building user interfaces and single-page applications.): [http://localhost:3003](http://localhost:3003)
- #5 (Angular - Framework for building single-page client applications using HTML and TypeScript.): [http://localhost:4200](http://localhost:4200)
